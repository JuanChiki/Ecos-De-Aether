# Ecos de Aether

RPG 2D de exploración para navegador, construido con HTML5, CSS3, JavaScript y Phaser.js.

## Estado actual

🚧 Fase 1: Base del proyecto — canvas de Phaser corriendo con una escena mínima.

## Cómo ejecutar

Este proyecto no usa build tools. Basta con servir la carpeta con un servidor local
(por ejemplo, la extensión "Live Server" de VS Code) y abrir `index.html`.

> No abras `index.html` directamente con doble clic (`file://`): algunas
> funcionalidades de Phaser y del navegador requieren que el juego se sirva
> por HTTP, aunque sea local.

## Tecnologías

- HTML5 / CSS3 / JavaScript
- [Phaser 3.90.0](https://phaser.io/) (vía CDN)
- JSON para datos del juego
- LocalStorage para guardado (próximamente)
